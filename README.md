# 🎨 ASCII Art Studio

### Transform Your Images Into ASCII Art

Turn ordinary images into creative text-based artwork using Python. ASCII Art Studio converts image pixels into characters based on their brightness, creating a unique terminal-inspired visual effect.

---

## ✨ Features

- 🖼️ **Image to ASCII** — Convert images into ASCII characters.
- 🎚️ **Brightness Mapping** — Map pixel brightness to different characters.
- 📐 **Image Resizing** — Control output dimensions for better results.
- ⚡ **Fast Processing** — Image processing with Python and Pillow.
- 🌐 **Streamlit Interface** — Interactive web-based experience.
- 🎨 **Creative Output** — Generate text-based artwork from your images.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core programming |
| Pillow (PIL) | Image processing |
| Streamlit | Web interface |

## ⚙️ How It Works

```text
     🖼️ Input Image
           |
           ▼
     Image Resizing
           |
           ▼
    Pixel Brightness
        Analysis
           |
           ▼
    Character Mapping
           |
           ▼
      ASCII Art
```

Each pixel's brightness is calculated and mapped to a character. Darker and brighter areas produce different characters, recreating the image in text form.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/eddiebrock911/ASCII-Art-Studio.git
```

### 2. Navigate to Project

```bash
cd ASCII-Art-Studio
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.
